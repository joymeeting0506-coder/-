## 历次关键修正已全部合并

- v3：修复三张车牌镜像；人物改为透明轮廓网格；稳定 Ogre 启动。
- v4：增加低墙、路沿、简化建筑和空间体量，改善 SLAM 固定特征。
- v4.1：降低 A / B 区墙体，避免挡住人偶；给红绿灯位置留缺口，解决穿模。
- v4.2：第二处红绿灯移回中央竖向通道；B 区 5 人改为 3+2 错位站位。
- v4.3：B 区人物朝向按相邻巡检路线重新设计，提升小车正面识别概率。

## 直接启动

```bash
cd ~/aic_ws/src/smart_community_gazebo
./launch_world.sh
```

## 接手后不要先改的内容

- 不要随意移动两个红绿灯、两处斑马线和右侧停车位。
- 不要用高墙围住 A / B 人偶区，否则会挡摄像头。
- 不要随意改变 B 区人物朝向，当前方案是按机器人经过的两条相邻巡检道路设计的。
- 不要把简化建筑扩到巡检通道里。
